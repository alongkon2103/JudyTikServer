# รูปผู้ชม Big Gift ค้างอันดับ และพรีวิวไลฟ์

- Alert, Big Gift, Top Likers และ Leaderboard ใช้รูปโปรไฟล์ TikTok ที่มากับอีเวนต์จริง ส่งผ่านตัวจับคู่และ snapshot ไปถึง Browser Source มี cache ต่อผู้ชมสำหรับอีเวนต์ถัดไปที่ไม่มีรูป ไม่เรียก Euler หรือ API เพิ่มเพื่อดึงรูป
- รับเฉพาะ HTTPS บนโดเมน CDN ของ TikTok ที่กำหนดไว้ใน allowlist และเปิด CSP รูปภาพให้ตรงกันทั้ง development/โปรแกรมติดตั้ง เมื่อไม่มีรูปหรือรูปหมดอายุ/โหลดไม่ได้ ใช้ไอคอนบุคคล ไม่ใช้ตัวอักษรแทนรูป
- Big Gift เปลี่ยนจากแสดงตาม duration เป็นค้างรายการของขวัญมูลค่าสูงสุด คิดมูลค่ารวมต่อคอมโบ (เหรียญต่อชิ้น × จำนวน) เรียงมากไปน้อย ไม่รวมเป็นยอดผู้ส่งคนเดียวแบบ Leaderboard
- เลือกแสดงได้ 1–10 อันดับ ค่าเริ่มต้น 3 เก็บประวัติอันดับที่ดีที่สุดสูงสุด 10 รายการไว้ในหน่วยความจำ เปลี่ยนจำนวนแสดงได้โดยไม่ลบอันดับที่ซ่อน ค้างหลังตัดการเชื่อมต่อ/โหลด Browser Source ใหม่ และ reconnect ห้องเดิม ล้างเมื่อกดล้างข้อมูล เริ่มห้องไลฟ์ใหม่ เปลี่ยนบัญชี หรือปิดโปรแกรม
- ปุ่มทดสอบแยกข้อมูลจำลองออกจากอันดับจริง ไม่เพิ่มของขวัญปลอมลงประวัติ
- พรีวิวใช้รูปของขวัญจริงที่รวมในโปรแกรม จำลองรายการเข้าทีละใบ สะสมยอด เปลี่ยนผู้นำและเลื่อนอันดับด้วย transform/opacity ทั้งในพรีวิวและ Browser Source
- จัดขนาดการ์ดตัวอย่างให้พอดีกรอบ รวมรูปตกแต่งธีม ย่อผลสปินแบบรายการเป็นป้ายสั้น และตัดคำอธิบายยาวซ้ำบน Slider

## อัปเดต Server

ฟิลด์ `bigGiftLimit` เป็น optional บน config ของ Big Gift โดย client ใหม่ส่ง capability `big-gift-ranking` ใน `x-judytik-overlay-features` ฝั่ง Server ไม่ส่งฟิลด์นี้ให้โปรแกรมรุ่นเก่า และรักษาค่าเดิมเมื่อรุ่นเก่าบันทึกโดยไม่มีฟิลด์นี้ ไม่ต้อง migration หรือตั้ง environment เพิ่ม

```powershell
Set-Location C:\JudyTikServer
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Pull ไม่สำเร็จ' }
npm --prefix server run build
if ($LASTEXITCODE -ne 0) { throw 'Build ไม่ผ่าน' }
pm2 restart judytik-backend --update-env
pm2 status
```

- ป้าย ×จำนวน ขยายตามจำนวนหลัก ใช้เลขตรงและคอลัมน์กว้างเท่ากัน ทดสอบถึง 1,000,000 ชิ้น
- รูปของขวัญในโหลเล็กลงตามขนาดโหล เอียงเล็กน้อยโดยไม่กลับหัว ใช้รูปจริงและคงจำนวนสะสม/ระบบของขวัญล้นเดิม
