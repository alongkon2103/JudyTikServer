# ความดังและการทดลองเล่นสื่อ

- คำสั่งเสียงและวิดีโอใน Actions มี `volume` แยกต่อคำสั่ง เป็นจำนวนเต็ม 0–100; 0 ปิดเสียง และถ้าไม่ระบุใช้ 100 เหมือนโปรแกรมเดิม
- เก็บค่าความดังกับพรีเซต รวมไฟล์ export/import โดยไฟล์เสียงยังผูกกับเครื่องเหมือนเดิม
- ปุ่มฟังตัวอย่างเล่นเฉพาะไฟล์ที่เลือก ไม่กดคีย์บอร์ดหรือเรียก Webhook และไม่ส่งภาพวิดีโอทดลองไป Browser Source
- ปรับความดังระหว่างฟังตัวอย่างได้ ปิดหน้าต่างหรือสลับบัญชีแล้วหยุดและเพิกถอนลิงก์ไฟล์
- FREE ฟังตัวอย่างไฟล์เสียงได้ วิดีโอยังต้องมี PRO ตามเดิม
- Soundpad มีความดังหลักและตัวปรับในหน้าต่างแก้เสียง คลังเสียงมีความดังตัวอย่างแยกจากค่าที่บันทึก
- TTS และ Spin ใช้ค่าความดังเดิม ส่วนเสียง WIN เพิ่มปุ่มฟังเสียงเพิ่ม/ลด และปรับความดังระหว่างเล่นได้

## API และโปรแกรมเก่า

Desktop ใหม่ส่ง `X-JudyTik-Preset-Features: media-volume` เพื่อรับฟิลด์ความดังครบจากเส้นทางพรีเซตและพรีเซตเกม

API ไม่ส่งฟิลด์ใหม่ให้โปรแกรมเก่าที่ใช้ตัวตรวจ schema แบบ strict และเก็บค่าความดังไว้เมื่อโปรแกรมเก่าแก้คำสั่งเสียงเดิม หากคำสั่งที่ใช้ไฟล์ซ้ำมีค่าความดังต่างกันและการแก้ไขจากโปรแกรมเก่าทำให้แยกไม่ได้ จะตอบ `409 PRESET_MEDIA_VOLUME_REQUIRES_UPDATE` เพื่อป้องกันบันทึกความดังผิดคำสั่ง

ต้อง deploy Backend ที่รองรับก่อนบันทึกค่าความดังใหม่ ไม่มี migration หรือ dependencies ใหม่ การล็อกซื้อเกมไม่มีการเปลี่ยนแปลงจากงานนี้
