# เปิดหน้าพรีเซตเกมชั่วคราวใน Desktop

ปิดการแสดงล็อกสิทธิ์ซื้อเกมในโปรแกรมด้วย `GAME_PRESET_PURCHASE_LOCK_ENABLED = false` ใน `shared/game-access-policy.js`

- หน้าเกมแสดงพรีเซตพร้อมใช้งาน โดยไม่อิงสถานะการซื้อจากร้าน
- ไม่เรียก `/me/game-licenses` เพื่อแสดงสถานะล็อกในหน้าเกม
- ข้อจำกัด FREE/PRO ยังเหมือนเดิม รวมถึง 10 Actions ต่อพรีเซตของ FREE
- ไม่เปลี่ยนข้อมูลการซื้อ วันหมดอายุ หรือสิทธิ์ PRO
- การปลดล็อกหน้าจอเดิมไม่มี migration; hotfix API ด้านล่างเปิดการใช้งานจริงเพิ่ม

## Hotfix API — 13 พฤศจิกายน 2026

Backend เปิดพรีเซตที่เผยแพร่แล้วให้ทุกบัญชีที่ล็อกอิน โดยไม่ตรวจการซื้อเกม อีเมลยืนยัน หรือวันหมดอายุสิทธิ์เกม และไม่เรียก JudyShop

ข้อจำกัด FREE/PRO ยังอยู่ รวมถึง 10 Actions ต่อพรีเซตของ FREE เกมฉบับร่างหรือหมวดที่ปิดยังไม่ถูกเปิดเผย ไม่แก้ข้อมูลสิทธิ์หรือวันหมดอายุในฐานข้อมูล

API `/me/game-licenses` ส่ง active access ของเกมที่เผยแพร่แล้วในรูปแบบเดิม เพื่อให้โปรแกรมรุ่นเก่าปลดล็อกด้วย หลัง deploy Backend ให้ผู้ใช้กด “โหลดล่าสุด” ในหน้าเกมแล้วเปิดพรีเซตใหม่ ไม่ต้องลง EXE ใหม่สำหรับ hotfix นี้

ไม่มี migration, dependency หรือ environment variable ใหม่ ใช้ git pull, build และ restart PM2 ตามปกติ
