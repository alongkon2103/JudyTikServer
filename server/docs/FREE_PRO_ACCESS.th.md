# ข้อจำกัด FREE / PRO

อัปเดต 12 พฤศจิกายน 2569

## FREE ใช้ได้อะไรบ้าง

| ฟีเจอร์ | FREE | PRO |
| --- | --- | --- |
| Actions | ไม่เกิน 10 รายการต่อพรีเซต | ตามขีดจำกัดเดิมของโปรแกรม |
| TTS / Actions เสียง / คีย์บอร์ด / Webhook | ใช้ได้ | ใช้ได้ |
| Alert Box, Top Likers, Goal Bar, Leaderboard, Spin ปกติ | ใช้ได้ | ใช้ได้ |
| Slider, Big Gift, Video Overlay, Subathon Timer, โหลของขวัญ | ล็อก | ใช้ได้ |
| Soundpad และปุ่ม Soundpad ในภาพรวม | ล็อก | ใช้ได้ |
| WIN รวม Overlay, Spin, คีย์ลัด และอีเวนต์เพิ่ม/ลด WIN | ล็อก | ใช้ได้ |

สิทธิ์ซื้อเกมจาก JudyShop ยังเป็นคนละระบบกับ PRO: PRO ไม่ปลดล็อกเกมที่ยังไม่ได้ซื้อ และ FREE ที่ซื้อเกมแล้วก็ยังมีข้อจำกัด 10 Actions ต่อพรีเซต

## การรักษาข้อมูลและการบังคับสิทธิ์

- API อ่านสิทธิ์จาก grant ในฐานข้อมูลตามบัญชี session และเวลา Server ไม่รับ plan ที่ client ส่งมา
- การตรวจและเขียนใช้ user lock เดียวกับ API เพิ่ม/ลดวันสิทธิ์ เพื่อลดปัญหาสิทธิ์เปลี่ยนชนกันระหว่างบันทึก
- บัญชี FREE สร้างหรือนำเข้าพรีเซตใหม่เกิน 10 Actions ไม่ได้ รวมถึงการนำเข้าจากเกมและไฟล์
- เมื่อ PRO หมดอายุ พรีเซตเดิมที่เกิน 10 ยังอยู่ครบ สามารถรักษาหรือลดจำนวนเดิมได้ แต่เพิ่มเกินจำนวนเดิมไม่ได้ ตัวทำงาน FREE จะใช้เฉพาะ 10 Actions แรกของชุดที่กำลังใช้
- ไม่ลบ WIN, Soundpad, ไฟล์สื่อ หรือค่าของ Overlay PRO เดิม เมื่อบัญชีกลับเป็น FREE
- FREE ยังบันทึก Overlay ที่ใช้ได้ โดยรักษาค่า PRO ที่ไม่แก้ไขไว้ รวมกรณี client รุ่นเก่าไม่ส่งฟิลด์ใหม่
- ป้องกันการเปลี่ยนค่า PRO หรือกู้คืน workspace PRO ผ่าน API restore แต่ไฟล์ archive เดิมยังคงอยู่และอ่านได้ การรวมบัญชีอัตโนมัติยังรักษาข้อมูลเดิมตามระบบเดิม
- ฝั่ง Desktop ตรวจซ้ำก่อนทำงานจริง รวม direct IPC, Browser Source, คิวงาน, วิดีโอและคีย์ลัด ไม่อาศัยการซ่อนปุ่มเพียงอย่างเดียว
- เมื่อหมดอายุ/ถูกลดสิทธิ์จะหยุดส่วน PRO ที่กำลังทำงาน โดยไม่ล้างค่าที่บันทึกไว้ และไม่หยุดการเชื่อม LIVE เพียงเพราะเป็น FREE
- ตรวจสิทธิ์ Server ใหม่ประมาณทุก 60 วินาที ระหว่างนั้นวันหมดอายุอ้างอิงเวลา Server บวกเวลาที่ผ่านไปแบบ monotonic เพื่อลดผลจากนาฬิกาเครื่องผู้ใช้คลาดเคลื่อน

| HTTP / code | ความหมาย |
| --- | --- |
| 403 `FREE_ACTION_LIMIT` | พรีเซตใหม่/การเพิ่มจำนวนเกินขีดจำกัด FREE |
| 403 `PRO_REQUIRED` | การเปลี่ยน/เรียกใช้ฟีเจอร์นี้ต้องมี PRO ที่ยังไม่หมดอายุ |

## ผู้ใช้เดิมที่ได้รับ PRO 30 วัน

ดำเนินการผ่าน admin API และตรวจสอบผลครบแล้ว **33 บัญชี** ตามบัญชี active ที่มีอยู่ ณ เวลาจับรายชื่อเริ่มงาน ทุกบัญชีในชุดนี้มีอีเมล

- FREE: เริ่ม PRO 30 วันจากเวลาที่ให้สิทธิ์
- PRO เดิม: บวก 30 วันจากวันหมดอายุเดิม ไม่ตัดสิทธิ์ที่ยาวกว่า
- ใช้ idempotency key ต่อบัญชีภายใต้ campaign `existing-users-pro30-20261112` ป้องกันบวกวันซ้ำ
- ไม่ใช่โบนัสอัตโนมัติสำหรับผู้สมัครใหม่หลังจับรายชื่อ และไม่ต้องรันคำสั่งให้โบนัสซ้ำตอน deploy
- หลักฐานการทำรายการและก่อน/หลังอยู่ใน entitlement operation/audit ของ Server รายงานนี้ไม่เก็บรหัสผ่าน คีย์ หรือรายชื่ออีเมล

## Deploy บน Windows Server

ระบบนี้ไม่มี migration, grants หรือ dependencies ใหม่ ใช้ `.env` เดิม ต้อง deploy backend แล้วแจก Desktop รุ่นที่มีตัวตรวจสิทธิ์นี้จึงจะได้หน้าจอและการหยุดงานครบ ผู้ใช้เดิมที่ได้รับโบนัสแล้วไม่ต้องให้สิทธิ์ซ้ำ

```powershell
& {
    Set-Location C:\JudyTikServer
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Pull ไม่สำเร็จ' }

    pm2 stop judytik-backend
    if ($LASTEXITCODE -ne 0) { throw 'หยุด Backend ไม่สำเร็จ' }

    npm --prefix server run build
    if ($LASTEXITCODE -ne 0) { throw 'Build ไม่ผ่าน ตรวจ error ก่อน restart' }

    pm2 restart judytik-backend --update-env
    if ($LASTEXITCODE -ne 0) { throw 'Restart ไม่สำเร็จ' }
    pm2 status
    Invoke-RestMethod http://127.0.0.1:4300/v1/health
}
```

## เกณฑ์ตรวจหลัง deploy

1. ใช้บัญชีทดสอบ FREE ใหม่: ต่อ LIVE และใช้ TTS/Actions/Overlay ที่อนุญาตได้
2. Action ที่ 10 บันทึกได้ รายการที่ 11 สร้าง/ทำสำเนา/นำเข้าเพิ่มไม่ได้
3. Soundpad, WIN และ Overlay PRO แสดงล็อก และเรียกข้ามหน้าจอตรง ๆ ไม่ทำงาน
4. เปลี่ยนบัญชีทดสอบเป็น PRO: ฟีเจอร์กลับมาใช้ได้ ค่าที่เคยบันทึกยังอยู่
5. ให้หมดอายุระหว่างเล่น: คิว PRO หยุดและ Browser Source ไม่แสดงงาน PRO ต่อ โดยพรีเซตและไฟล์ยังอยู่
6. ไม่ปรับสิทธิ์บัญชีลูกค้าจริงเพียงเพื่อทดสอบ downgrade ใช้บัญชีทดสอบแยก
